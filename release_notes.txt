### API Gateway, Routing & Observability

- Implemented the API Gateway using Spring Cloud Gateway to route requests to Customer, Product, and Order services.
- Added a global filter to generate and propagate `X-Correlation-Id` across downstream services for request tracking.
- Implemented Redis-based rate limiting using the Token Bucket algorithm to protect API endpoints and return `429 Too Many Requests` when limits are exceeded.
- Integrated Circuit Breaker and fallback mechanisms using Resilience4j to handle service failures gracefully.
- Integrated Zipkin with Micrometer Tracing to monitor distributed requests across microservices.
- Improved log correlation by including `traceId` and `correlationId` to connect application logs with distributed traces.
- Implemented client-side load balancing using Spring Cloud LoadBalancer and Eureka with `lb://` routing.
- Configured multiple Order Service and Gateway instances to test request distribution and high availability.
- Added Nginx as an external load balancer in front of multiple Gateway instances, experimenting with Round Robin and Least Connections strategies.
- Integrated Swagger UI (OpenAPI) into the API Gateway to provide a centralized interface for exploring and testing Customer, Product, and Order service APIs through a single entry point.


*Key concepts covered:*

*   *Definition:* An API Gateway acts as a centralized entry point for client requests to a system, sitting between the clients and the internal microservices.
*   *Core Functions:*
    *   *Request Routing:* It directs incoming traffic to the appropriate backend services.
    *   *Authentication:* It validates user identity before allowing access to internal resources.
    *   *Rate Limiting:* It controls the number of requests a client can make to prevent system overload or abuse.
*   *Benefits:* By offloading these cross-cutting concerns (like security and traffic management) to a dedicated layer, the internal microservices can focus solely on their specific business logic.

This architectural pattern helps improve *security, **scalability, and **manageability* of large-scale distributed systems.
